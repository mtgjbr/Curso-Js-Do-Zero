MONGODB + MONGOOSE - RESUMO PARA REVISÃO
===================================

PARTE 1: O QUE É MONGODB (o banco de dados)
================================================

O QUE É?
--------
MongoDB é um banco de dados. Serve pra GUARDAR os dados da sua
aplicação de forma permanente (usuários, produtos, mensagens, etc) --
diferente de uma variável no código, que some quando o servidor
reinicia.

A diferença dele pros bancos "tradicionais" (como MySQL, PostgreSQL):

BANCOS TRADICIONAIS (SQL / relacionais)
  - Guardam dados em TABELAS, com LINHAS e COLUNAS fixas.
  - Toda linha da tabela precisa seguir a mesma estrutura rígida.
  - Ex: tabela "usuarios" com colunas: id, nome, email, idade.

MONGODB (NoSQL / não-relacional)
  - Guarda dados em formato parecido com objetos JSON, chamados de
    "documentos".
  - Documentos ficam agrupados em "coleções" (collections).
  - A estrutura é flexível: dois documentos na mesma coleção podem
    ter campos diferentes entre si (embora na prática, com Mongoose,
    a gente geralmente define uma estrutura fixa mesmo assim).

TERMOS E EQUIVALÊNCIAS (pra quem já conhece SQL)
  SQL              MongoDB
  ---------------- ----------------
  Tabela           Coleção (collection)
  Linha            Documento (document)
  Coluna           Campo (field)

EXEMPLO DE UM "DOCUMENTO" NO MONGODB (parece um objeto JS!)
  {
    _id: "64f1a2b3c9d1e2f3a4b5c6d7",
    nome: "Maria",
    email: "maria@email.com",
    idade: 28
  }

O `_id` é gerado automaticamente pelo MongoDB pra cada documento --
é o identificador único dele (parecido com uma chave primária).


ONDE O MONGODB RODA?
------------------------
- Localmente na sua máquina (instalado no computador), OU
- Na nuvem, usando o MongoDB Atlas (serviço oficial gratuito/pago da
  própria MongoDB, muito usado em projetos de estudo e produção)

O Atlas te dá uma "connection string" (uma URL) que você usa no
código pra conectar no banco. Algo mais ou menos assim:
  mongodb+srv://usuario:senha@cluster.mongodb.net/nomeDoBanco


================================================
PARTE 2: O QUE É MONGOOSE
================================================

O QUE É?
--------
Mongoose é uma biblioteca (ODM -- Object Data/Document Modeling) que
funciona como uma "ponte" entre seu código Node.js e o MongoDB.

Por que usar Mongoose em vez de conectar direto no MongoDB?
  - Permite definir uma ESTRUTURA fixa pros seus dados (schema),
    mesmo o MongoDB sendo flexível por natureza -- isso evita erros
    bobos, tipo salvar "idade" como texto sem querer.
  - Faz VALIDAÇÃO automática dos dados antes de salvar.
  - Fornece MÉTODOS prontos pra criar, buscar, atualizar e deletar 
    dados (CRUD), de um jeito mais simples que escrever tudo na mão.
  - Funciona muito bem junto com Express (ex: dentro de uma rota,
    você usa o Model do Mongoose pra buscar dados e devolver no
    res.json()).


INSTALAÇÃO
------------
npm install mongoose


CONECTANDO AO BANCO
------------------------
const mongoose = require('mongoose');

mongoose.connect('mongodb://127.0.0.1:27017/meuBanco')
  .then(() => console.log('Conectado ao MongoDB!'))
  .catch((err) => console.log('Erro ao conectar:', err));

- Se o banco for local: 'mongodb://127.0.0.1:27017/nomeDoBanco'
- Se for Atlas (nuvem): usa a connection string que o Atlas te dá


OS 3 CONCEITOS-CHAVE DO MONGOOSE
-------------------------------------

1) SCHEMA (o "molde" dos dados)
   Define quais campos existem, o tipo de cada um, e regras de
   validação.

   const mongoose = require('mongoose');

   const usuarioSchema = new mongoose.Schema({
     nome: { type: String, required: true },
     email: { type: String, required: true, unique: true },
     idade: Number,
     criadoEm: { type: Date, default: Date.now }
   });

   Tipos comuns: String, Number, Boolean, Date, Array, ObjectId
   Opções comuns: required (obrigatório), unique (não repete),
                  default (valor padrão se não informado)

2) MODEL (a "ferramenta" de trabalho, criada a partir do Schema)
   O Model é o que você realmente usa no código pra interagir com o
   banco (criar, buscar, atualizar, deletar).

   const Usuario = mongoose.model('Usuario', usuarioSchema);

   Atenção: o Mongoose pega o nome 'Usuario' (singular, maiúsculo) e
   automaticamente cria/usa uma coleção chamada 'usuarios' (plural,
   minúsculo) no banco.

3) DOCUMENT (um "registro" individual, instância do Model)
   Cada documento é um objeto JS criado a partir do Model,
   representando UM item guardado no banco.


CRUD COM MONGOOSE (Create, Read, Update, Delete)
------------------------------------------------------

CREATE (criar)
  const novoUsuario = new Usuario({ nome: 'João', email: 'joao@ex.com' });
  await novoUsuario.save();

  // ou de forma mais direta:
  await Usuario.create({ nome: 'João', email: 'joao@ex.com' });

READ (buscar)
  const todos = await Usuario.find();               // busca todos
  const um = await Usuario.findOne({ nome: 'João' }); // busca um
  const porId = await Usuario.findById('64f1a2...');  // busca por _id

UPDATE (atualizar)
  await Usuario.findByIdAndUpdate('64f1a2...', { idade: 30 });

DELETE (deletar)
  await Usuario.findByIdAndDelete('64f1a2...');

Observação: todos os métodos do Mongoose retornam PROMISES, por isso
o uso constante de await (ou .then()) -- assim como vimos com fs e
outras operações assíncronas do Node.


EXEMPLO JUNTANDO COM EXPRESS (o fluxo completo)
------------------------------------------------------
const express = require('express');
const mongoose = require('mongoose');
const app = express();

app.use(express.json());

mongoose.connect('mongodb://127.0.0.1:27017/meuBanco');

const usuarioSchema = new mongoose.Schema({
  nome: String,
  email: String
});
const Usuario = mongoose.model('Usuario', usuarioSchema);

// rota que cria um usuário novo
app.post('/usuarios', async (req, res) => {
  try {
    const usuario = await Usuario.create(req.body);
    res.status(201).json(usuario);
  } catch (err) {
    res.status(500).json({ erro: err.message });
  }
});

// rota que lista todos os usuários
app.get('/usuarios', async (req, res) => {
  const usuarios = await Usuario.find();
  res.json(usuarios);
});

app.listen(3000);


COMO LER A DOCUMENTAÇÃO OFICIAL
------------------------------------
Existem duas docs relacionadas, não confunda:

1) mongoosejs.com/docs -> doc do MONGOOSE (a biblioteca em si).
   Estrutura: Guides (Schemas, Models, Queries, Validation,
   Middleware, Connections) -- comece sempre por "Guides > Schemas"
   e "Guides > Models", é a base de tudo.

2) mongodb.com/docs -> doc do MONGODB (o banco em si, e também tem
   uma seção específica de integração com Mongoose). Útil quando a
   dúvida é sobre o BANCO (ex: como o Atlas funciona), não sobre a
   biblioteca.

Dica de leitura: a doc do Mongoose costuma mostrar bastante código de
exemplo direto -- copie, rode, e vá alterando pra entender o que cada
parte faz, igual fizemos com Webpack e Express.


RESUMO EM UMA FRASE
----------------------
MongoDB é o banco de dados que guarda os dados em documentos (tipo
JSON) organizados em coleções; Mongoose é a biblioteca que conecta o
Node.js a esse banco, permitindo definir uma estrutura fixa (schema),
validar dados e fazer CRUD de forma simples usando Models.
